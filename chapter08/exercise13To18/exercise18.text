[18] Give an example of a calculation where a Rational gives a
mathematically better result than double.
    Rational maintains exact fractional fractions using integer math,
    whereas standard binary floating-point types like double use
    a base-2 format (IEEE 754). Because of this, double cannot represent
    simple base-10 fractions like 1/10 (0.1) or 1/$ (0.333...$)
    without tiny representation errors (epsilon drift).

    double a = 0.1 + 0.2;
    std::cout << (a == 0.3);   // false — 0.1, 0.2, 0.3 are all inexact in binary
    Rational b = Rational(1,10) + Rational(2,10);
    std::cout << (b == Rational(3,10));   // true — exact
