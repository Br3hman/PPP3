# Programming -- Principles and Practice Using C++ (3rd Edition)

This repository contains my solutions and exercises from the book "Programming: Principles and Practice Using C++" (3rd Edition) by Bjarne Stroustrup.

## Setup

- **Compiler:** g++ 15.2.0 (MSYS2)
- **Standard:** C++23

## Structure

The repository is organized by chapters, with each chapter containing:
- Exercise solutions
- Examples from the book
- Additional practice code
